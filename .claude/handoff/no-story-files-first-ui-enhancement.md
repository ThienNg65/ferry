## Goal
Customer says Ferry content is hard to see and focus on. Make the file list own the screen: dock collapsed by default, one unmistakable active pane, selection as the loudest thing in the list. Agreed scope this round is Phases 1–2 only; Phase 3 is a later round.

## What Worked
- Keeping `zebraRowClass` in `utils/rowStyle.ts` and only dropping its use in `FileRow`. The plan said to make it return `''`, but `monitor/ProcessTable.vue` also uses it, so changing the util would silently change that table.
- `Tab` is limited to the pane root as event target so Tab still walks toolbar buttons for keyboard users. The plan said "when not in an input", which would have trapped focus nav.

## What Didn't Work
- Launching the app for visual checks. `npm run dev` built fine, the renderer served on localhost:5173 and Electron started, but the process then exited with code 0 (likely the window was closed). The Claude browser pane cannot drive Electron, and the renderer depends on the preload `window.api`, so it cannot run standalone in a browser. No visual results exist.
- Unit tests for the dock auto-open watcher and `activePane`: both live in a component and a store that reads `localStorage` at init, and the test env has no DOM, so none were written.
